# 📊 Call Center Analytics Dashboard – Power BI

## 🚀 Project Overview
This project presents a fully dynamic Call Center Analytics Solution built using Power BI.

The goal was not just to create visuals, but to design an end-to-end BI solution — starting from data integration to building an interactive, user-driven reporting experience.

---

## 🔹 Data Sources
The data was collected from two different sources:

- Microsoft Access Database (2023 Data)
- Excel File (2024 Data)

Both datasets were integrated and consolidated into a unified dataset using Power Query.

---

## 🔹 Data Preparation (ETL)

- Data cleaning and transformation using Power Query
- Data consolidation (Append Queries)
- Query optimization and disabling staging tables
- Data type standardization

---

## 🔹 Data Modeling

- Created a dedicated Calendar Table using DAX
- Implemented proper relationships between tables
- Enabled Time Intelligence functions (YoY, QoQ, MoM)
- Built a structured and optimized data model

---

## 🔹 Advanced DAX Implementation

### ✅ Dynamic KPI Comparison
- Vs Last Year (LY)
- Vs Last Quarter (LQ)
- Vs Last Month (LM)

### ✅ Field Parameters
- Dynamic switching between:
  - Total Calls
  - Calls Reached
  - Deals Closed
  - Deals Value

### ✅ Additional Business Logic
- Dropped Calls Calculation
- Deal Segmentation:
  - High Volume Deals
  - Low Volume Deals
  - No Deals
- Conditional Formatting based on performance variance

---

## 🔹 Dashboard Features

- Interactive KPI Cards (New Cards Visual)
- Dynamic Stacked Column Chart
- Bookmark-based Toggle Filter Panel
- Fully slicer-driven user experience
- Dynamic text & symbol formatting inside KPIs
