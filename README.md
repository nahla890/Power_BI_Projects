# 📊 Power BI Projects Portfolio

Welcome to my Power BI projects repository! Here you will find a collection of interactive dashboards covering various business domains like Sales, HR, and Hospitality.

## 📂 Projects Overview

- AdventureWorks Dashboard Comprehensive sales and customer analysis.
- HR Dashboard Employee performance and workforce insights.
- Call Center Dashboard Monitoring KPIs and service levels.
- Hotels Dashboard Analysis of bookings and revenue management.
- Sales Report Detailed sales performance across different regions.

## 🛠️ Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query (M Language)
- SQL  Excel  Access (Data Sources)

## 🚀 How to View
Each folder contains the `.pbix` file. You can download and open them using Power BI Desktop.
